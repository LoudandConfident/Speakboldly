# Full library and client email actions

1. Replace the current standalone Clients Code.gs with the complete Updated-Code.gs supplied to the owner. Do not paste it alongside old copies of Code.gs, Sessions.gs, TeacherDocuments.gs, EmailActions.gs or LibraryActions.gs: the complete file already contains all of them.
2. Preserve CLIENT_SHEET_ID, CLIENT_SYNC_KEY and the existing reminder trigger. Save.
3. Run setupFullLibrary once and authorize Google Drive and mail access. This creates one private Speak Boldly Full library folder, with Materials, Exams, Exercises, Progress reports, Final reports and Listening tracks. Folder IDs stay in Script Properties and are shared by all existing teacher devices.
4. Deploy a New version of the same existing web-app deployment. Keep the /exec URL unchanged.
5. Refresh Teacher Portal and connect the same Clients sheet on each existing device. Full library reads the same Drive folders. Small file uploads are limited to 5 MB; for larger books use the direct Drive folder link inside the relevant folder, then Refresh. Existing website PDFs are listed separately; copy/upload them to the shared Drive folder to send restricted viewer links.
6. From Full library, Send to client grants Google Drive viewer access to the selected client's registered email and emails the link. The client opens it signed into Google with that email. Viewer permission prevents editing; it is not a guarantee against copying or downloading. LibrarySendLog records sends; uncertain sends must be checked before another send.
7. Authorize beside each client opens confirmation email, the existing Progress report, Final report and Registration/payment confirmation templates, and exam selection. Review the completed template fields and send the PDF as an email attachment. EmailLog records acceptance; check a test inbox before live use. Template binaries remain the same ones already built.
8. Exam selection currently saves the client/exam choice in the shared sheet. It does not yet send a working timed interactive-exam invitation. The recommended next implementation is an Apps Script-backed exam link with a unique private token, server deadline, submissions sheet, automatic multiple-choice marking and teacher-reviewed written answers. The prepared private Node server is an alternative, not required for Google Drive material sharing or these email attachments.
