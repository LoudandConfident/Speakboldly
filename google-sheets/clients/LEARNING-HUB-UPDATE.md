# Consultation and Native English update

One combined Apps Script update enables the consultation email with pictures and the shared Native English controls. It also includes all previous calendar, confirmations, exam submissions and other Clients script changes.

1. Open [UnifiedCode.gs](https://raw.githubusercontent.com/LoudandConfident/Speakboldly/main/google-sheets/clients/UnifiedCode.gs), copy the complete file, and replace Code.gs in your existing Clients Apps Script project. Save. Keep the existing Script Properties.
2. Deploy → Manage deployments → pencil beside your existing Web app → Version: New version → Deploy. Keep Execute as: Me and access: Anyone. Keep the same deployment URL.
3. Refresh the website or close and reopen the installed app.
4. In Instructor Portal, open Edit Native English. Keep Automatic selected, or choose Manual, select one of the 12 listening links and 24 novels, then Publish selections.

No setup function or new Script Properties are needed for these additions. The free SB Studio tools do not need an AI key.

## What changes

- Programs has a Request consultation email composer. The subject includes the visitor’s name. The recipient is fixed to speakboldly16@gmail.com. Up to two JPG/PNG/WebP pictures, 1 MB each, can be attached. Requests are logged in Instructor requests and repeated submissions with the same request ID do not send twice.
- Automatic Native English content remains on the current selection through 14 January 2027 in Cairo. It changes on 15 January, then on the first of each month. Existing October custom content is preserved through the freeze. Manual selections stay fixed until you change them or return to Automatic.
- Jane Eyre is the initial monthly novel. The 24 public-domain novels open inside the website. Each book remembers its page on the same browser/device; no account or cross-device reading-position sync is added.
- SB Studio has 365 daily roleplay briefs. The free Roleplay Room copies a prompt to use in the student’s own ChatGPT account. Voice Lab provides model audio, local recording/playback and word recognition where the browser supports it. Recordings are not uploaded to Speak Boldly. Model voices, microphone access and recognition depend on the device/browser.
- Circular section guides explain each Learning Hub destination.

## Quick check

Use your own email in Request consultation, attach a small assessment picture, and send once. Check your inbox and Instructor requests. Then choose a manual Native English link/novel, Publish, and open Native English on another device. Return to Automatic if you want the January schedule.
