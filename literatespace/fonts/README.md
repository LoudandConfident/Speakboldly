Beyond typography
=================

Fraunces (display headings) and DM Sans (body and controls) are self-hosted here.
Source: Fontsource variable packages, version 5.3.0. Both families use the SIL Open Font License 1.1; their license files are included alongside the fonts.

Fraunces includes optical size and weight axes; DM Sans includes the weight axis. Latin subsets are used to keep downloads small.
